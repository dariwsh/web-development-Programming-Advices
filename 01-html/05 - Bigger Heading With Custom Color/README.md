# Lesson 05 - Bigger Heading With Custom Color

---

# 📘 Introduction

In this lesson, we learned about:

# Styling Headings

is:

> HTML elements can be styled using the `style` attribute, which allows you to apply CSS directly to a specific element.

---

# 🎯 Main Idea

You can use the inline `style` attribute on HTML elements to change their appearance, such as font size and color.

This lesson demonstrates how to make a heading larger and give it a custom color using inline CSS.

---

# 💡 Example

**A simple HTML page with custom styled heading:**

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>05 - Bigger Heading With Custom Color</title>
  </head>

  <body>
    <h1 style="font-size: 200%; color: blueviolet">My First Heading</h1>
    <h2>My Second Heading</h2>
    <h3>My Third Heading</h3>
    <h4>My Fourth Heading</h4>
    <h5>My Fifth Heading</h5>
    <h6>My Sixth Heading</h6>
  </body>
</html>
```

---

# ✨ Custom Heading Styles

**✅ Inline style on h1:**

```html
<h1 style="font-size: 200%; color: blueviolet">My First Heading</h1>
```

**✅ Standard h2 heading:**

```html
<h2>My Second Heading</h2>
```

**✅ Standard h3 heading:**

```html
<h3>My Third Heading</h3>
```

---

# 🧠 Rules of Inline Styling

```text
✔️ The style attribute goes inside the opening HTML tag
✔️ Multiple CSS properties are separated by semicolons
✔️ font-size: 200% makes text twice the default size
✔️ color: blueviolet sets text color using a CSS color name
✔️ Inline styles only affect the specific element they are on
```

---

# 🧩 Style Properties Table

| Property | Value | Effect |
|----------|-------|--------|
| font-size | 200% | Doubles the text size | 
| color | blueviolet | Changes text color to blue-violet | 

---

# ✅ Summary

| Concept | Meaning |
| ---------- | ------------------------------- |
| style attribute | Applies CSS directly to an element |
| font-size | Controls the size of the text |
| color | Controls the text color |
| percentage | Relative to the parent element's size |
| inline style | Only affects the element it is written on |
