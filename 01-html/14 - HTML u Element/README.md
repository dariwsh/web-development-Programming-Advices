# Lesson 14 - HTML u Element

---

# 📘 Introduction

In this lesson, we learned about:

# HTML u Element

is:

> The HTML `<u>` element represents a span of text with an unarticulated, though explicitly rendered, non-textual annotation, such as labeling the text as being a proper name in Chinese text or a misspelled word.

---

# 🎯 Main Idea

The `<u>` element underlines text in HTML.

Unlike the old practice of using `<u>` purely for visual styling, modern HTML uses it to mark text that needs a non-textual annotation, such as proper names or misspellings.

---

# 💡 Example

**A simple HTML page using the u element:**

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>14 - HTML u Element</title>
  </head>
  <body>
    <p>hello <u>hello world</u> world</p>
  </body>
</html>
```

---

# ✨ The u Element

**✅ Underlined text inside a paragraph:**

```html
<p>hello <u>hello world</u> world</p>
```

---

# 🧠 Rules of the u Element

```text
✔️ The <u> element underlines text
✔️ It is not only for visual styling — it has semantic meaning
✔️ Use <u> for proper names, misspellings, or other annotations
✔️ Avoid using <u> to style links — use CSS instead
✔️ The default visual effect is underlined text
```
