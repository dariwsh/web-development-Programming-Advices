# Lesson 13 - HTML i and em Elements

---

# 📘 Introduction

In this lesson, we learned about:

# Italic Text vs Emphasized Text

is:

> The HTML `<i>` element defines a part of text in an alternate voice or mood, while the `<em>` element defines emphasized text, and browsers display it as italic by default.

---

# 🎯 Main Idea

Both `<i>` and `<em>` make text italic, but they have different semantic meanings.

`<i>` is used for text in a different voice or mood (such as technical terms, foreign words, or thoughts), while `<em>` indicates emphasized text that carries stronger meaning.

---

# 💡 Example

**A simple HTML page comparing i and em:**

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>13 - HTML i and em Elements</title>
  </head>
  <body>
    <p>I am learning <i>HTML</i></p>

    <p>This is <em>very important</em></p>
  </body>
</html>
```

---

# ✨ Italic vs Emphasized Text

**✅ Italic text (alternate voice):**

```html
<p>I am learning <i>HTML</i></p>
```

**✅ Emphasized text:**

```html
<p>This is <em>very important</em></p>
```

---

# 🧠 Rules of i and em Elements

```text
✔️ <i> displays text in italics for alternate voice or mood
✔️ <em> displays text in italics with semantic emphasis
✔️ Browsers display both as italic by default
✔️ Use <em> for content that needs emphasis
✔️ Use <i> for technical terms, foreign words, or thoughts
✔️ Screen readers may stress <em> differently from <i>
```

---
