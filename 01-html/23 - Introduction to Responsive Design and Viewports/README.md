# Lesson 23 - Introduction to Responsive Design and Viewports

---

# 📘 Introduction

In this lesson, we learned about:

# Responsive Design and Viewports

is:

> The viewport meta tag controls how a webpage is displayed on mobile devices. Without it, mobile browsers render pages at desktop widths and then shrink them, making text unreadable.

---

# 🎯 Main Idea

Responsive design ensures web pages look good on all screen sizes. The `<meta name="viewport">` tag is the foundation, telling the browser to match the page width to the device width and set an initial zoom level.

---

# 💡 Example

**A simple example:**

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>23 - Introduction to Responsive Design and Viewports</title>
  </head>
  <body></body>
</html>
```

---

# ✨ Key Points

**Viewport Meta Tag:**

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

**Width=device-width:**

```text
Sets the viewport width to match the device screen width.
```

**Initial-scale=1.0:**

```text
Sets the initial zoom level to 100%.
```

---

# 🧠 Rules of Responsive Design

```text
✔️ Always include the viewport meta tag for mobile-friendly pages
✔️ width=device-width matches the screen width
✔️ initial-scale=1.0 prevents unwanted zooming
✔️ Responsive design adapts layout to any screen size
```

---

# 🧩 Viewport Properties

| Property | Value | Purpose |
|----------|-------|---------|
| `width` | `device-width` | Matches screen width |
| `initial-scale` | `1.0` | Sets default zoom level |
| `user-scalable` | `yes/no` | Allows or prevents pinch zoom |

---

# ✅ Summary

| Concept | Meaning |
|---------|---------|
| Viewport | Visible area of a web page on a device |
| Meta Viewport | Tag that controls mobile rendering |
| Responsive Design | Adapting layout to all screen sizes |
| Device Width | Actual screen width in CSS pixels |
| Initial Scale | Starting zoom level of the page |
