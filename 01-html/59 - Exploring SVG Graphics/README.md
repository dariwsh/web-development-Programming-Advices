# Lesson 59 - Exploring SVG Graphics

---

# 📘 Introduction

In this lesson, we learned about:

# SVG Graphics

is:

> SVG (Scalable Vector Graphics) is an XML-based markup language for describing two-dimensional vector graphics. It allows for scalable images that maintain quality at any size.

---

# 🎯 Main Idea

SVG provides a way to create vector-based graphics directly in HTML, enabling scalable and resolution-independent images that can be styled with CSS and animated with JavaScript.

---

# 💡 Example

**A simple example:**

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>59 - Exploring SVG Graphics</title>
  </head>
  <body>
    
  </body>
</html>
```

---

# ✨ Key Points / Breaking Down the Example

## What is SVG

SVG stands for Scalable Vector Graphics. It is an XML-based format for defining vector graphics.

```html
<svg width="100" height="100">
  <circle cx="50" cy="50" r="40" stroke="green" stroke-width="4" fill="yellow" />
</svg>
```

**Key benefits:**
- Graphics scale without quality loss
- Can be edited with CSS and JavaScript
- Typically smaller file size for simple graphics
- Supports animation and interactivity

---

# 🧠 Rules / Key Concepts

```text
✔️ SVG graphics are resolution-independent
✔️ SVG uses XML syntax within <svg> tags
✔️ All SVG elements must be properly closed
✔️ SVGs can be styled with CSS
✔️ SVGs can be animated and scripted with JavaScript
✔️ Common SVG shapes: <rect>, <circle>, <ellipse>, <line>, <path>, <polygon>, <polyline>
```

# 🧩 Summary Table

| Part | Meaning | Example |
| --------- | ----------------------------- | ----------------- |
| `<svg>` | SVG container element | `<svg width="200" height="200">` |

| `<rect>` | Rectangle shape | `<rect width="100" height="50" />` |
