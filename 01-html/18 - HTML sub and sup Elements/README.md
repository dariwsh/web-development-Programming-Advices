# Lesson 18 - HTML sub and sup Elements

---

# 📘 Introduction

In this lesson, we learned about:

# HTML sub and sup Elements

is:

> The HTML `<sub>` element defines subscript text, and the `<sup>` element defines superscript text. Subscript appears half a character below the baseline, while superscript appears half a character above the baseline.

---

# 🎯 Main Idea

The `<sub>` and `<sup>` tags are used to display subscript and superscript text, respectively.

They are commonly used for chemical formulas, mathematical exponents, footnotes, and ordinal indicators.

---

# 💡 Example

**A simple HTML page using sub and sup:**

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>18 - HTML sub and sup Elements</title>
  </head>

  <body>
    <p>CO<sub>2</sub></p>
    <p>x<sup>2</sup> + y<sup>2</sup> = z<sup>2</sup></p>
  </body>
</html>
```

---

# ✨ sub and sup Elements

**✅ Subscript for chemical formula:**

```html
<p>CO<sub>2</sub></p>
```

**✅ Superscript for mathematical exponents:**

```html
<p>x<sup>2</sup> + y<sup>2</sup> = z<sup>2</sup></p>
```

---

# 🧠 Rules of sub and sup Elements

```text
✔️ <sub> displays subscript text — half a character below the baseline
✔️ <sup> displays superscript text — half a character above the baseline
✔️ They only affect the text inside them, not the surrounding text
✔️ Use <sub> for chemical formulas, footnotes, and math indexes
✔️ Use <sup> for exponents, ordinal indicators, and math powers
```
