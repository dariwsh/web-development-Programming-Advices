# 📘 Introduction

In this lesson, we learned about:

# The HTML `<head>` Element

is:

> The `<head>` element contains metadata about the HTML document that is not displayed on the page itself. It includes information for browsers, search engines, and social media platforms.

---

# 🎯 Main Idea

The HTML `<head>` element provides essential document metadata such as character encoding, viewport settings, SEO information, and links to external resources like CSS and JavaScript.

---

# 💡 Example

**A simple example:**

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8"> <!-- Specifies the character encoding for the HTML document -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0"> <!-- Sets the viewport to control layout on mobile browsers -->
    <meta name="description" content="Learn the essentials of HTML5"> <!-- Provides a brief description of the page, which can be used by search engines -->
    <meta name="keywords" content="HTML5, Web Development, Learn HTML"> <!-- Supplies search engines with keywords for SEO -->
    <meta name="author" content="John Doe"> <!-- Defines the author of the document -->
    <title>Understanding the HTML `<head>` Element</title> <!-- The title of the document shown in the browser's title bar or tab -->
    <link rel="stylesheet" href="styles.css"> <!-- Link to an external CSS file -->
    <script src="script.js"></script> <!-- Link to an external JavaScript file -->
</head>

<body>
    <h1>Welcome to our HTML5 tutorial!</h1> <!-- Main heading of the web page -->
</body>
</html>
```

---

# ✨ Key Points / Breaking Down the Example

## Meta Tags for Character Encoding

Specifies how text is encoded in the document.

```html
<meta charset="UTF-8">
```

## Meta Tags for Viewport

Controls the layout on mobile browsers.

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

## Meta Tags for SEO

Provides search engines with page information.

```html
<meta name="description" content="Learn the essentials of HTML5">
<meta name="keywords" content="HTML5, Web Development, Learn HTML">
<meta name="author" content="John Doe">
```

## The `<title>` Element

Sets the browser tab title and bookmark name.

```html
<title>Understanding the HTML `<head>` Element</title>
```

## External Resources

Links to CSS and JavaScript files.

```html
<link rel="stylesheet" href="styles.css">
<script src="script.js"></script>
```

---

# 🧠 Rules / Key Concepts

```text
✔️ <head> contains metadata, not visible page content
✔️ <title> is required and displays in the browser tab
✔️ <meta charset="UTF-8"> is essential for proper text encoding
✔️ <meta viewport> is necessary for responsive mobile design
✔️ <link> connects external CSS stylesheets
✔️ <script> can load or inline JavaScript
✔️ Content inside <body> is what users see on the page
```
