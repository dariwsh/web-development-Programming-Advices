# Lesson 15 - HTML small Element

---

# 📘 Introduction

In this lesson, we learned about:

# HTML small Element

is:

> The HTML `<small>` element defines smaller text, such as copyright and legal text, or side comments. It reduces the text size to one size smaller than the surrounding text.

---

# 🎯 Main Idea

The `<small>` tag makes text appear smaller than the normal text size.

It is commonly used for fine print, copyright notices, disclaimers, or other side comments that should be visually de-emphasized.

---

# 💡 Example

**A simple HTML page using the small element:**

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>15 - HTML small Element</title>
  </head>

  <body>
    <p>This is normal text</p>
    <p>Copyright <small>2025</small></p>
    <p><small>This is small text</small></p>

    <p>hello <small>world</small></p>
  </body>
</html>
```

---

# ✨ The small Element

**✅ Small text inline in a paragraph:**

```html
<p>Copyright <small>2025</small></p>
```

**✅ Small text as its own block:**

```html
<p><small>This is small text</small></p>
```

**✅ Small text inline:**

```html
<p>hello <small>world</small></p>
```

---

# 🧠 Rules of the small Element

```text
✔️ The <small> element renders text one size smaller
✔️ It is used for side comments, disclaimers, and fine print
✔️ It does not change the importance or semantics of the text
✔️ The visual effect depends on the browser's default styles
✔️ Commonly used for copyright and legal text
```
