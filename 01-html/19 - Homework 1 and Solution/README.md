# ✨ Practice Sections

## Part 1 - Text Formatting

**✅ Bold and strong:**

```html
<p>
  The word <b>bold</b> is visual, while <strong>strong</strong> indicates
  importance.
</p>
```

**✅ Italic and emphasis:**

```html
<p>
  The <i>italic</i> tag is used for titles, while <em>emphasis</em> adds
  meaning.
</p>
```

**✅ Highlighted text:**

```html
<p>This is <mark>highlighted text</mark>.</p>
<p>
  <mark style="background-color: green; color: white">Green highlight</mark>
</p>
```

**✅ Subscript and superscript:**

```html
<p>H<sub>2</sub>O and E = mc<sup>2</sup></p>
```

## Part 2 - Inline and Block Elements

**✅ Span element:**

```html
<p>A <span style="color: red">span inside paragraph</span></p>
```

**✅ Preformatted text:**

```html
<pre>
 Preformatted text
 respects spaces
 </pre>
```

**✅ Horizontal rule:**

```html
<hr />
```

**✅ Line break:**

```html
<p>This line has a break<br />Notice the split</p>
```

## Part 3 - Text Changes

**✅ Deleted and inserted text:**

```html
<p><del>Old</del> <ins>New</ins></p>
```

**✅ Small text:**

```html
<p><small>Disclaimer text</small></p>
```

**✅ Underlined text:**

```html
<p><u>Note:</u> underline example</p>
```

## Part 4 - Headers

**✅ Header hierarchy:**

```html
<h2>Headers</h2>
<h3>Title</h3>
<h4>Subsection</h4>
<h5>Details</h5>
<h6>Item</h6>
```

# 🧠 Rules of HTML Practice

```text
✔️ Combine multiple HTML tags in a single document
✔️ Use semantic tags (strong, em) for meaning
✔️ Use visual tags (b, i, mark) for appearance
✔️ Keep heading hierarchy logical and ordered
✔️ Use inline styles for quick styling
✔️ Use <hr> to separate sections visually
```
