# Lesson 17 - HTML del and ins Elements

---

# 📘 Introduction

In this lesson, we learned about:

# HTML del and ins Elements

is:

> The HTML `<del>` element defines text that has been deleted from a document, while the `<ins>` element defines text that has been inserted into a document. Browsers usually strike through deleted text and underline inserted text.

---

# 🎯 Main Idea

The `<del>` and `<ins>` tags are used together to show document changes, such as corrections or edits.

`<del>` marks removed content with a strikethrough, and `<ins>` marks added content with an underline.

---

# 💡 Example

**A simple HTML page using del and ins:**

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>17 - HTML del and ins Elements</title>
  </head>
  <body>
    <p>i like <del>apple</del> <ins>banana</ins></p>
    <p>~~this is deleted text~~</p>
    <p><u>this is inserted text</u></p>
    <p>hello <del>world</del> <ins>beautiful world</ins></p>
  </body>
</html>
```

---

# ✨ del and ins Elements

**✅ Replacing deleted text with inserted text:**

```html
<p>i like <del>apple</del> <ins>banana</ins></p>
```

**✅ Deleted text:**

```html
<p>~~this is deleted text~~</p>
```

**✅ Inserted text:**

```html
<p><u>this is inserted text</u></p>
```

**✅ Combined deletion and insertion:**

```html
<p>hello <del>world</del> <ins>beautiful world</ins></p>
```

---

# 🧠 Rules of del and ins Elements

```text
✔️ <del> marks text that has been deleted from a document
✔️ <ins> marks text that has been inserted into a document
✔️ Browsers usually strike through <del> text
✔️ Browsers usually underline <ins> text
✔️ They are often used together to show changes
✔️ They have semantic meaning for document revisions
```

---

# 🧩 Text Change Table

| Tag | Visual | Semantic | Purpose |
|-----|--------|----------|---------|
| del | Strikethrough | Deleted text | Shows removed content | 
| ins | Underline | Inserted text | Shows added content | 

---

# ✅ Summary

| Concept | Meaning |
| ---------- | ------------------------------- |
| del | Deleted text, shown with strikethrough |
| ins | Inserted text, shown with underline |
| Use case | Document changes, revisions, corrections |
| Semantic | Marks content as changed in a document |
