# Lesson 04 - Heading Elements

---

# 📘 Introduction

In this lesson, we learned about:

# HTML Headings

is:

> HTML headings are titles or subtitles that you want to display on a webpage. They help define the hierarchy and structure of your content.

---

# 🎯 Main Idea

HTML provides six levels of headings, from `<h1>` to `<h6>`.

`<h1>` defines the most important heading, while `<h6>` defines the least important heading. Browsers display them with decreasing size by default.

---

# 💡 Example

**A simple HTML page with headings:**

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>04 - Heading Elements</title>
  </head>

  <body>
    <h1>this is heading 1</h1>
    <h2>this is heading 2</h2>
    <h3>this is heading 3</h3>
    <h4>this is heading 4</h4>
    <h5>this is heading 5</h5>
    <h6>this is heading 6</h6>
  </body>
</html>
```

---

# ✨ Heading Elements

**✅ Main heading:**

```html
<h1>this is heading 1</h1>
```

**✅ Secondary heading:**

```html
<h2>this is heading 2</h2>
```

**✅ Tertiary heading:**

```html
<h3>this is heading 3</h3>
```

**✅ Fourth-level heading:**

```html
<h4>this is heading 4</h4>
```

**✅ Fifth-level heading:**

```html
<h5>this is heading 5</h5>
```

**✅ Sixth-level heading:**

```html
<h6>this is heading 6</h6>
```

---

# 🧠 Rules of HTML Headings

```text
✔️ HTML headings are defined with <h1> to <h6> tags
✔️ <h1> is the largest and most important heading
✔️ <h6> is the smallest and least important heading
✔️ Headings should be used in order (h1 before h2)
✔️ Search engines use headings to index the structure of a page
```

---

# 🧩 Headings Table

| Tag | Level | Default Size | Usage |
|-----|-------|--------------|-------|
| h1 | 1 | Largest | Main page title | 
| h2 | 2 | Large | Section headings | 
| h3 | 3 | Medium | Subsection headings | 
| h4 | 4 | Smaller | Sub-subsection headings | 
| h5 | 5 | Very small | Minor headings | 
| h6 | 6 | Smallest | Least important headings | 

---

# ✅ Summary

| Concept | Meaning |
| ---------- | ------------------------------- |
| h1 | Largest heading / page title |
| h2-h6 | Subheadings of decreasing importance |
| Order | Use headings in hierarchical order |
| Default | Browsers set decreasing font sizes |
