# Lesson 07 - HTML br Tag

---

# 📘 Introduction

In this lesson, we learned about:

# Line Breaks

is:

> The HTML `<br>` element defines a line break. It is useful for writing poems or addresses where line breaks are significant.

---

# 🎯 Main Idea

The `<br>` tag inserts a single line break within a paragraph.

It is an empty element, meaning it does not have a closing tag. Use it when you want to start a new line without creating a new paragraph.

---

# 💡 Example

**A simple HTML page with line breaks:**

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>07 - HTML br Tag</title>
  </head>
  <body>
    <p>
      hi , this is a paragraph <br />
      and this is a new line
    </p>
  </body>
</html>
```

---

# ✨ The br Element

**✅ Using br inside a paragraph:**

```html
<p>
  hi , this is a paragraph <br />
  and this is a new line
</p>
```

---

# 🧠 Rules of the br Tag

```text
✔️ The <br> tag inserts a single line break
✔️ It is an empty/void element — no closing tag needed
✔️ Use <br> to break lines within a paragraph
✔️ Do NOT use <br> to create spacing between paragraphs — use <p> instead
✔️ <br /> is the self-closing form used in XHTML-style HTML
```

---

# 🧩 br vs p Table

| Tag | Purpose | Effect |
|-----|---------|--------|
| br | Line break | Moves to next line within same paragraph | 
| p | Paragraph | Creates a new paragraph with margin | 

---

# ✅ Summary

| Concept | Meaning |
| ---------- | ------------------------------- |
| br | Inserts a line break |
| Empty element | No closing tag required |
| Use case | Poetry, addresses, within paragraphs |
| Not for | Creating vertical spacing between paragraphs |
