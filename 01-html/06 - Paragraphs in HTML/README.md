# Lesson 06 - Paragraphs in HTML

---

# 📘 Introduction

In this lesson, we learned about:

# HTML Paragraphs

is:

> The HTML `<p>` element defines a paragraph. A paragraph always starts on a new line, and browsers automatically add some white space (a margin) before and after a paragraph.

---

# 🎯 Main Idea

The `<p>` tag is used to create paragraphs of text in HTML.

Each paragraph starts on a new line by default, and you can style paragraphs using the `style` attribute to change font size, color, and font family.

---

# 💡 Example

**A simple HTML page with paragraphs:**

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>06 - Paragraphs in HTML</title>
  </head>
  <body>
    <p style="font-size: 30px; color: brown; font-family: fantasy">
      Hi , this is a paragraph
    </p>
    <p>Hi , this is a second paragraph</p>
    <p>
      Hi , this is a third paragraph Lorem ipsum dolor sit amet consectetur
      adipisicing elit. Nostrum labore esse laboriosam culpa quas, perferendis
      exercitationem cupiditate a quia porro.
    </p>
    <p>Hi , this is a fourth paragraph</p>
  </body>
</html>
```

---

# ✨ Paragraph Styles

**✅ Styled paragraph with inline CSS:**

```html
<p style="font-size: 30px; color: brown; font-family: fantasy">
  Hi , this is a paragraph
</p>
```

**✅ Simple paragraph:**

```html
<p>Hi , this is a second paragraph</p>
```

**✅ Paragraph with long text:**

```html
<p>
  Hi , this is a third paragraph Lorem ipsum dolor sit amet consectetur
  adipisicing elit. Nostrum labore esse laboriosam culpa quas, perferendis
  exercitationem cupiditate a quia porro.
</p>
```

---

# 🧠 Rules of HTML Paragraphs

```text
✔️ The <p> tag defines a paragraph
✔️ Browsers automatically add margin before and after <p>
✔️ Each <p> starts on a new line by default
✔️ You can style paragraphs with the style attribute
✔️ font-size controls text size
✔️ color controls text color
✔️ font-family controls the typeface
```

---

# 🧩 Paragraph Properties Table

| Property | Example | Effect |
|----------|---------|--------|
| font-size | 30px | Sets the text size to 30 pixels | 
| color | brown | Sets the text color to brown | 
| font-family | fantasy | Sets the font to a fantasy typeface | 

---

# ✅ Summary

| Concept | Meaning |
| ---------- | ------------------------------- |
| p | Defines a paragraph in HTML |
| Block element | Starts on a new line by default |
| margin | Space automatically added by browsers |
| style attribute | Applies CSS directly to the element |
| font-size | Controls text size |
| color | Controls text color |
| font-family | Controls the font type |
