# Lesson 09 - Horizontal Rules hr

---

# 📘 Introduction

In this lesson, we learned about:

# Horizontal Rules

is:

> The HTML `<hr>` element represents a thematic break between paragraph-level elements, such as a change of scene in a story or a shift in topic within a section.

---

# 🎯 Main Idea

The `<hr>` tag inserts a horizontal rule (a line) into the page, creating a visual break between sections of content.

You can also style the horizontal rule using inline CSS to change its thickness, color, and border style.

---

# 💡 Example

**A simple HTML page with horizontal rules:**

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>09 - Horizontal Rules hr</title>
  </head>
  <body>
    <p>This is the first section of the text.</p>

    <hr />

    <p>This is the second section of the text.</p>

    <hr />

    <p>Before the break.</p>

    <hr style="border: none; height: 2px; background-color: red" />

    <p>After the break.</p>

    <hr style="border: none; height: 6px; background-color: red" />
  </body>
</html>
```

---

# ✨ Horizontal Rules

**✅ Default horizontal rule:**

```html
<hr />
```

**✅ Thin red horizontal rule:**

```html
<hr style="border: none; height: 2px; background-color: red" />
```

**✅ Thick red horizontal rule:**

```html
<hr style="border: none; height: 6px; background-color: red" />
```

---

# 🧠 Rules of Horizontal Rules

```text
✔️ The <hr> tag creates a thematic break (horizontal line)
✔️ It is an empty element — no closing tag needed
✔️ Default style is a thin gray line spanning the page
✔️ You can style it with inline CSS using border and background-color
✔️ Useful for separating sections of content
```

---

# 🧩 hr Styles Table

| Style | CSS | Effect |
|-------|-----|--------|
| Default | No inline style | Standard thin gray line | 
| Thin red | border: none; height: 2px; background-color: red | 2px red line | 
| Thick red | border: none; height: 6px; background-color: red | 6px red line | 

---

# ✅ Summary

| Concept | Meaning |
| ---------- | ------------------------------- |
| hr | Thematic break / horizontal rule |
| Empty element | Self-closing, no closing tag |
| Default | Thin gray line across the page |
| Styled | Can use CSS for custom appearance |
| Use case | Separating sections of content |
