# Lesson 16 - HTML mark Element

---

# 📘 Introduction

In this lesson, we learned about:

# HTML mark Element

is:

> The HTML `<mark>` element represents text which is marked or highlighted for reference or notation purposes, due to the marked passage's relevance in the enclosing context.

---

# 🎯 Main Idea

The `<mark>` tag highlights text with a default yellow background to draw attention to specific content.

It is used to mark text that is relevant or noteworthy in the current context, such as search results or key terms in a document.

---

# 💡 Example

**A simple HTML page using the mark element:**

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>16 - HTML mark Element</title>
  </head>
  <body>
    <p>hello my favorite number is <mark>4</mark></p>
    <p>this is normal text</p>
    <p><mark>this is mark text</mark></p>
    <p>hello <mark>world</mark></p>
    <p>hello <mark>world</mark></p>
    <p>hello <mark>world</mark></p>
  </body>
</html>
```

---

# ✨ The mark Element

**✅ Highlighting a number inside a sentence:**

```html
<p>hello my favorite number is <mark>4</mark></p>
```

**✅ Highlighted text as its own line:**

```html
<p><mark>this is mark text</mark></p>
```

**✅ Highlighting a word inside a sentence:**

```html
<p>hello <mark>world</mark></p>
```

---

# 🧠 Rules of the mark Element

```text
✔️ The <mark> element highlights text with a default yellow background
✔️ It is used for relevance in the current context
✔️ It is not the same as <em> or <strong> — it does not change importance
✔️ The default styling may vary across browsers
✔️ Useful for search results and highlighted passages
```
